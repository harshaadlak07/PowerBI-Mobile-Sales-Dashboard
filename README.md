# Mobile Sales Dashboard - Power BI Project

## Project Overview
This Power BI dashboard provides insights into mobile sales performance through interactive visualizations and KPI tracking.

## Key Features
- Total Sales Analysis
- Total Quantity Tracking
- Transaction Analysis
- Average Price Analysis
- MTD Analysis
- Same Period Last Year Analysis
- Sales by City
- Sales by Mobile Model
- Payment Method Analysis
- Quarterly & Yearly Trends

## Tools Used
- Power BI
- DAX
- Power Query
- SQL
- Data Modeling
